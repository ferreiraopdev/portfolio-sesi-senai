# Portfólio | SESI & SENAI - Marcos Ferreira Alves 3°G
Projeto desenvolvido por Marcos Ferreira Alves do 3° G da turma de informática.
Esse projeto consiste na elaboração de um portfólio em parceria com os requisitos do portfólio da instituição SESI.
O portfólio deve permitir o cadastro das atividades e perguntas pessoais de um usuário ja definido pelo backend.
O objetivo principal dele é mostrar todas as atividades e autoavaliação durante o último ano deste curso.

Professores: Carlos Wilton e Kleber Galvão

### Backend
Backend feito em Express, Sequelize e SQLite
Bibliotecas de produção: Nodemon
Arquitetura: MVC

Este projeto de portfólio funciona a partir da identificação de um único usuário
Para o cadastro desse usuário é necessário da modificação do backend, pois ja tem um usuário padrão
(Mais informações no README do back)

### Frontend
Frontend feito em React utilizando react router dom
