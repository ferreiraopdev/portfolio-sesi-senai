# Portfólio | SESI & SENAI - Marcos Ferreira Alves 3°G

### Backend
Backend feito em Express, Sequelize e SQLite
Bibliotecas de produção: Nodemon
Arquitetura: MVC

Este projeto de portfólio funciona a partir da identificação de um único usuário
Para o cadastro desse usuário é necessário da modificação do backend, pois ja tem um usuário padrão
(Mais informações no README do back)

### Frontend
Frontend feito em React utilizando react router dom
