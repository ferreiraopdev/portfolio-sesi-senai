# Back-end do portfólio
Para instalar dependências: npm i
Para rodar servidor: npm run dev
Para modificação do usuário:
    1° - Acesse o arquivo "server.js" dentro da pasta src
    2° - Altere as informações no prompt de inicialização do usuario.create
    3° - Adicione seu perfil na pasta public, e troque o nome da foto padrão (309555591.jpg) para o nome da sua foto
